# ClarityFi – Product Requirements Document (Short Version)

## Product Overview

**Product Name:** ClarityFi
**Category:** Personal Finance / FinTech

### Vision

Help users understand, manage, and make smarter financial decisions through simple, actionable financial insights.

### Problem Statement

Consumers generate large amounts of financial data through UPI, cards, and bank transactions but lack visibility into their spending habits, shared expenses, and financial decisions. Existing solutions address these problems separately, creating fragmented experiences.

---

## Target Users

### Riya – Overwhelmed Earner

Wants visibility into monthly spending and recurring expenses.

### Arjun – Reluctant Splitter

Needs a simple way to split and settle shared expenses with friends and roommates.

### Meera – Confused Decision Maker

Wants help understanding EMI offers, insurance plans, and financial products.

---

## Key Objectives

* Increase spending awareness
* Simplify expense splitting
* Improve financial decision-making
* Drive long-term engagement through personalized insights

### Success Metrics

* 60% of users discover a new spending pattern within 7 days
* 40% Day-30 retention
* 25% Day-90 retention
* 35% of active users create a split group
* 50% reduction in expense settlement time

---

## MVP Features

### 1. Spend Clarity Dashboard

* SMS-based transaction parsing
* Automatic spend categorization
* Monthly and weekly spending trends
* AI-powered spending insights

### 2. Smart Expense Splitter

* Create expense groups
* Equal or custom bill splits
* Automatic settlement calculations
* UPI payment integration

### 3. Financial Decision Explainer

* EMI analysis
* Insurance policy evaluation
* Hidden charge detection
* Plain-language recommendations

## Key Risks

| Risk                       | Mitigation                          |
| -------------------------- | ----------------------------------- |
| SMS permission denial      | Manual expense entry                |
| Low retention              | Personalized financial insights     |
| Privacy concerns           | On-device processing and encryption |
| Complex financial products | Rule-based recommendation engine    |
